# Reporting period reconciliation scenario

Proposed manual check: choose one reporting period and department, sum matching finance source rows, then compare the cost KPI against the Excel, native Power BI and HTML views where equivalent filters exist. Ensure the period boundary and treatment of missing dates are identical. Clear filters and compare the unfiltered totals. Record discrepancies rather than assuming that all interfaces share the same filter implementation. This is a test procedure, not a new acceptance result.
